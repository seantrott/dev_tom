# dev_tom
Charting the developmental trajectory of FB/ToM capacities throughout pre-training.

All packages required for running scripts are located in the `requirements.txt` file: 

``
conda create -n dev_tom_env python=3.10
``

``
conda activate dev_tom_env
``

``
pip install -r requirements.txt
``

The .csv files that store individual head attentions (per model, per checkpoint, per layer, per head) are too large to store in this repository. You can find them at the Open Science Framework instead: https://osf.io/ncypd/overview
